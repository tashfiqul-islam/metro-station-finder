# Contributing

Set up and run the project with [development](docs/development.md). Task flow, ticket states and review rules are in the [workflow](docs/agents/workflow.md); required checks are in [quality gates](docs/agents/quality-gates.md). Report vulnerabilities as described in [SECURITY.md](SECURITY.md).

Open pull requests against `feature/metro-rebuild` using the [pull request template](.github/pull_request_template.md) until the default-branch cutover; step 6.4 of the [cutover runbook](docs/agents/cutover-runbook.md) then changes the base branch in every document that names it, together.
