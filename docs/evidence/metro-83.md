# METRO-83: cut the cost of the slowest script test files

Labels: **Repo-verified** (measured in this checkout, numbers below), **Hosted** (read from the pull request's CI table), **Unverified** (not measured). Base: `origin/feature/metro-rebuild` at `98f5dd5` (METRO-82 merged, `bun test --parallel=4`). Local machine: Windows 11, 20 logical cores, Bun 1.4.4, Node 26. Raw timing logs were kept in the session scratchpad and are not committed.

## Why

Under `--parallel=4` the slowest files bound the wall time (see [METRO-82](metro-82.md)). Three files were slow because they spawned the same heavy tool many times for assertions that one run can answer.

## Parallel safety

All three changed files create their directories with `mkdtemp` (under `.local/` or the system temp directory) and never change the working directory or the environment; the shared state is per test-file process. `tsc-build.test.ts` keeps its bounded EBUSY retry when removing the copy.
