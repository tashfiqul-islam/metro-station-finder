**Web-verified, coordinator browser observation:** the public site showed a Google Maps failure and disabled location input. Route Fare remained usable: Uttara North → Motijheel displayed BDT 100. Footer showed v0.0.2. This is an observation of the public deployment, whose commit was not established; it does not prove successful location or walking journeys at the baseline.

**Repo-verified, data:** coordinate and fare arrays have no recorded publisher, effective date, source version, or update process. There are 16 unique labels in each dataset, 256 finite fares, a symmetric matrix, zero diagonal, and off-diagonal values from 20 to 100 in multiples of ten. Five positional labels differ; see glossary. These checks prove internal properties, not real-world accuracy.

## Inferred

- Positional correspondence suggests the five differently named entries represent the same stations. No stable identifier proves that mapping.
- A displayed walking route can have a different length from the card's geographic distance. Neither nearest selection nor card calculation ranks stations by pedestrian route length.
- A new search can retain old distance while waiting for a response. Source does not reset distance, clear the directions error on success, or guard delayed results by request identity. Runtime race behavior remains untested.

## Unknown

Official station names, coordinate datum/accuracy/entrances, fare authority, effective date, concessions, payment classes, operational station coverage, and update ownership are unverified. Successful live autocomplete, walking routing, mobile navigation, accessibility and recovery were not browser-verified. Google geometry availability is not established: loader requests places, does not explicitly request geometry, and pins no SDK version.
