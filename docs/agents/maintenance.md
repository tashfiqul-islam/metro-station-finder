## Cloudflare preview (METRO-13)

Same-repository pull requests get a Worker `metro-scaffold-pr-<number>` on workers.dev, deployed by the `preview` job of `.github/workflows/quality.yml` after `checks`, `build` and `security` pass; `preview-cleanup.yml` deletes it when the pull request closes. The job is outside the `Quality gates` aggregate. Secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` live only in the GitHub environment `preview`; a missing one fails the job with a message naming it. The token needs Workers Scripts edit for this account only; the owner rotates it (the first token expires 2026-12-03). Rollback: `wrangler rollback --name metro-scaffold-pr-<number>` returns the preview to its previous version (the job exercises it, then redeploys the checked commit). Never run these against `metro-scaffold` (production). Decisions: [specification](../specifications/cloudflare-preview.md), [ADR-0006](../adr/0006-cloudflare-preview.md).
