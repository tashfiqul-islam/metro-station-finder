# Architecture

**Confirmed / Repo-verified (legacy baseline `af903d7`, not the rebuild):** the baseline uses Next pages/components/services/utils, not an implemented layered workspace. Inspect [manifest](https://github.com/tashfiqul-islam/metro-station-finder/blob/af903d7a2c1bf08165cfcf4a00ca0c0d73eedead/package.json), [TypeScript config](https://github.com/tashfiqul-islam/metro-station-finder/blob/af903d7a2c1bf08165cfcf4a00ca0c0d73eedead/tsconfig.json) and relevant imports before changing structure.

**Confirmed / Repo-verified:** `packages/core` contains executable domain/application synthetic status code with no dependencies. `apps/web` and `apps/api` compose inward. Its standalone TypeScript check excludes runtime/framework globals; `scripts/boundaries.ts` rejects external and escaping imports plus dependency declarations. The boundary guard is narrow; dependency-cruiser enforces the layers: core imports only core, `packages/contracts` imports only core and Valibot, `apps/web` and `apps/api` never import each other, `apps/web` imports no runtime value from core (types only), and contracts is reached only through its public entry `src/index.ts`. Each rule is proven red by a violating fixture in `scripts/layering.test.ts` (see [ADR-0003](../adr/0003-contracts.md) and [ADR-0002](../adr/0002-runtime-topology.md)).

**Required future boundary:** application owns ports when needed; adapters implement them; apps compose. Keep API clients on plain `fetch` with Valibot schemas from `packages/contracts` ([ADR-0003](../adr/0003-contracts.md)); a REST/OpenAPI layer needs a new ADR. Version station/fare data; database and native UI require demonstrated need and explicit scope. No speculative ports/adapters are created by this scaffold.

For package/import/provider changes, identify affected boundaries, installed lockfile versions and applicable ADRs. Material decisions live in [docs/adr](../adr/0000-template.md); read the [foundation baseline ADR](../adr/0001-foundation-baseline.md) first and record a new ADR before introducing a material decision. Do not fabricate ADR links. Every ADR follows the template's header, status vocabulary (MADR 4.0.0) and required sections including `Confirmation`, checked by `scripts/adr.test.ts`. Contract, permissions and gate-policy changes need explicit task scope. The import-graph gate (`bun run imports:check`) enforces cycles, unresolved imports and the layering rules, and the core boundary guard enforces core purity; both run in `check` and CI. See [quality gates](quality-gates.md) and [workspace decisions](../development.md).
