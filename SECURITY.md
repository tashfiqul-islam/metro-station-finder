# Security policy

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/tashfiqul-islam/metro-station-finder/security/advisories/new). Do not open public issues or pull requests for security problems, and do not include credentials, personal locations or addresses in any report.

Scans that run on this repository are described in [quality gates](docs/agents/quality-gates.md) and [security guidance](docs/agents/security.md). A passing scan is not a security clearance.
